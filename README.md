# Agent Job Tracker

A GitHub Pages-ready front-end prototype for an agent operations and production tracker.

## Files

- `index.html` — page structure and components
- `style.css` — visual theme and responsive styling
- `app.js` — sample tracker data, filtering, stats, job creation modal and UI behavior

## Current status

This version uses **sample data only**. It does not yet write to Google Sheets.

## Next integration

Connect `app.js` to a Google Apps Script web-app endpoint that reads/writes your Google Sheet. The front end can remain hosted on GitHub Pages.
